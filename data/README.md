# Public data package

This directory contains **derived manuscript-facing summaries**, not the complete internal research workspace.

Included files:

- `baseline_stability_summary.json` — equal-smoothness baseline stability landscape.
- `interaction_and_retention_summary.json` — dense 216,027-cell interaction study and contraction-margin retention summaries.
- `robustness_summary.json` — off-grid robustness checks, boundary refinement, and fixed-stratum symbolic cross-check summary.
- `full_regularity_mismatch_summary.json` — full-regularity fixed-average audit, including the mismatch coordinate and admissibility counts.
- `symbolic_root_certificate.json` — public certificate summary for the generic cubic root structure and sensitivity result.

These files contain derived numerical and algebraic results used to support the manuscript. Internal notes, exploratory artifacts, model/tool interaction records, novelty-review materials, OSF workflow files, and private research logs are intentionally excluded.

All contraction claims remain conditional on the reproduced two-agent Empirical Law 4.3 used in the manuscript.
